# 🐱 貓咪照護日誌

記錄家裡貓咪的大小事：基本資料、每天喝水吃飯、體重趨勢、疫苗、驅蟲、就醫、用藥、美容、花費與生活回憶。
純前端網頁，可直接發布到 GitHub Pages；搭配免費的 Firebase 就能把資料存在雲端，讓家人用連結即時一起編輯。

## 功能

| 分頁 | 內容 |
| --- | --- |
| 🏠 總覽 | 每隻貓的年齡（自動由生日計算，含「約人類幾歲」與生命階段）、今天喝水 / 吃飯、7 天平均喝水、最新體重、到期提醒、本月花費 |
| 🐾 貓咪 | 名字、照片、生日、性別、品種、毛色、結紮、到家日、晶片號碼、理想體重、固定醫院與電話、保險、過敏 / 慢性病、備註 |
| 📅 每日 | 喝水量 (ml)、乾飼料 / 濕食 (g)、零食、食慾、尿尿 / 便便次數、便便狀況、嘔吐次數、精神狀況、玩耍時間、備註（全部選填） |
| 💉 健康 | 疫苗、驅蟲 / 心絲蟲預防、就醫、用藥、美容清潔；填了「下次日期」就會自動進到總覽提醒 |
| ⚖️ 體重 | 體重與 BCS 體態評分，自動畫出趨勢折線圖 |
| 💰 花費 | 分類記帳，並自動把醫療 / 美容費用一起統計 |
| 📸 回憶 | 日期 + 標題 + 照片 + 內容的生活紀錄 |
| 🔗 資料 | 雲端同步（家庭共享空間）、匯出 JSON 備份、匯出每日紀錄 CSV、合併 / 覆蓋匯入、資料快照連結、清除資料 |

其他：深色模式、手機版面、照片自動壓縮、依貓咪篩選檢視。

## 資料存在哪裡

- **沒設定雲端**：資料只存在各自裝置的瀏覽器 localStorage。換裝置、清除瀏覽器資料就會不見，請定期匯出備份。
- **開啟雲端同步**：資料存在你自己的 Firebase Firestore（Google 免費雲端資料庫），
  家人打開同一個共享連結就能**即時一起編輯**，任何人改了，其他人的畫面會自動更新。
  每台裝置也會留一份快取，離線時照樣能看能記，恢復網路後自動上傳。

## 開啟雲端同步（約 5 分鐘，只需做一次）

1. 到 <https://console.firebase.google.com/> 用 Google 帳號登入 → **建立專案**（名稱例如 `cat-diary`，Google Analytics 可關閉）。
2. 左側 **建構 → Firestore Database → 建立資料庫**，地區選 `asia-east1 (台灣)`，模式選 **正式版 (production mode)**。
3. 建好後切到 **規則 (Rules)** 分頁，把本專案 [`firestore.rules`](firestore.rules) 的內容整段貼上 → **發布**。
4. 回到 **專案設定 (⚙️) → 一般 → 你的應用程式**，按 **`</>`（網頁）** 註冊一個應用程式（不用勾 Hosting），
   畫面會出現一段 `firebaseConfig = { ... }`。
5. 把那段內容貼進 [`assets/firebase-config.js`](assets/firebase-config.js)，取代 `null`，然後 commit / push。
6. 打開網站 →「資料」分頁 → **建立雲端家庭空間**（目前的資料會一起上傳）→ **複製共享連結** 傳給家人。

家人打開共享連結就會自動加入，之後直接打開網站也會自動接回同一個空間。

> **安全性說明**：共享連結裡的空間 ID 是 24 碼隨機字串，等同於鑰匙——**拿到連結的人都能檢視與修改**，請只傳給信任的人。
> `firebaseConfig` 本來就是公開給網頁使用的設定，放在公開 repo 沒關係，權限由 Firestore 規則控管。
> 免費額度（每天 5 萬次讀取、2 萬次寫入、1 GB 儲存）對一個家庭來說非常充裕。

## 不用雲端時怎麼共享

1. 在「資料」分頁按 **產生分享連結**（建議勾選「不包含照片」，連結才不會太長）。
2. 把連結用 LINE / 訊息傳給家人，家人打開後資料會載入他的瀏覽器，可以直接新增或修改。
3. 他再按一次「產生分享連結」把新連結傳回來，你打開後選擇「合併」即可。

合併規則：同一筆紀錄比對 `id`，以 `updatedAt` 較新的為準；雙方各自新增的紀錄都會保留。
資料量大時（尤其含照片），改用「匯出 JSON → 傳檔案 → 合併匯入」更穩定。

## 本機預覽

直接用瀏覽器打開 `index.html` 即可；或啟動簡易伺服器：

```powershell
python -m http.server 8080
# 然後開啟 http://localhost:8080
```

## 發布到 GitHub Pages

```powershell
git remote add origin https://github.com/<你的帳號>/cat-diary.git
git branch -M main
git push -u origin main
```

推上去後到 repo 的 **Settings → Pages → Build and deployment → Source** 選 **GitHub Actions**，
等 Actions 跑完，網站就會在 `https://<你的帳號>.github.io/cat-diary/`。

> 若要讓別人也能編輯**原始碼**，到 **Settings → Collaborators** 邀請對方；
> 一般家人只要用上面的共享連結就夠了，不需要 GitHub 帳號。
